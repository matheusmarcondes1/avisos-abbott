Configurações

Ajustes do painel

Os horários das reuniões ficam no banco: são cadastrados aqui uma única vez e valem para todas as TVs, que recebem as alterações na hora. As preferências de exibição (fonte, fundo do relógio) são deste aparelho.

Séries de reuniões

Crie mais de uma série para cobrir turnos diferentes — por exemplo, manhã e tarde, com horários e supervisores próprios. Edite as janelas da série selecionada abaixo. As alterações são salvas no banco automaticamente.

Dados

O cronograma vive no banco. Use a planilha para conferir os horários ou para cadastrar muitas janelas de uma vez — a importação substitui as janelas da série selecionada, no banco, para todas as TVs.

Cronograma da série selecionada (abre no Excel)

Colunas do CSV: Início; Fim; Área; Supervisor; Cadeia (horários como 09:00; Cadeia em branco ou SEG…SÁB).

Informações

Este é um projeto pessoal e de código aberto — uma plataforma genérica de avisos/andon para produção, criada por iniciativa própria. Funciona apenas como apoio à organização e à gestão da rotina e não se integra a sistemas corporativos. Guarda somente os horários das reuniões cadastrados aqui e os sinais operacionais de chamado (tipo, mesa, etapa, horário) — nenhuma informação pessoal.
